# Agile process

Two-week sprints. GitHub Issues are the authoritative backlog and status source.

## Workflow
Backlog -> Ready -> In Progress -> Review -> Done.
Every issue includes user value, acceptance criteria, estimate, and dependencies.
Feature branches and PRs reference issues. CI and review precede merge.

## Ceremonies
Sprint planning, asynchronous daily progress check, backlog refinement, sprint review,
and retrospective. Report completed versus incomplete stories, blockers, CI state,
observed velocity (only after actual data), and next sprint candidates.

## Definition of Ready
Clear objective, testable criteria, dependencies identified, sized appropriately.

## Definition of Done
Acceptance criteria demonstrated, tests and security checks passing, documentation updated,
review completed, and PR merged. Production deployment separately verified when applicable.
